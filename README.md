# 🌡️ chuanyiUtil · 26度穿衣计算器

一个纯前端、零依赖的「26度穿衣法」小工具，奶龙卡通主题，手机优先适配。
配套一只原创小黄龙吉祥物（SVG/Canvas 手绘，无版权风险）。

> 在线体验：可直接双击打开 `index.html`，或开启 GitHub Pages 后访问
> `https://xuchangbin0927.github.io/chuanyiUtil/`

## 什么是 26度穿衣法？

源自儿科医生总结的经验公式：人体舒适温度约为 26℃，

```
26℃ − 当天气温 = 需要靠衣服补足的「温度」
```

每件衣服的保暖性折算为温度值（薄棉毛衫 1℃ ~ 厚羽绒服 9℃），
两者相加刚好 26℃ 左右即为合适穿搭。

## 功能

- 🌡️ 温度滑块（-10 ~ 35℃）实时计算
- 👕 内搭 / 中间层 / 外套 三层衣物点选，标签实时汇总
- 📊 温度计可视化（绿色区间 = 目标 ±1℃），自动建议加/脱哪件
- 🎚️ 怕冷体质目标 +2℃ / 怕热 −2℃，大风天、雨天提醒
- ✨ 「帮我搭」一键生成 3 套推荐搭配（温暖天气可不穿外套）
- 📸 生成「今日穿搭卡片」PNG：可保存下载、调起系统分享
- 🐉 奶龙风格奶油黄主题 + 浮动小黄龙动画
- 📱 移动端优先：安全区适配、触控目标加大、PWA meta

## 技术

- 单文件 `index.html`：原生 HTML + CSS + JavaScript，零依赖、无后端
- 穿搭卡片：Canvas 2D 绘制，高度随内容自适应
- 分享：`navigator.share`（Web Share API），不支持时自动降级为保存图片
